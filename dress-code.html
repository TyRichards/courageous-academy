Dress Code

Please arrive ready to dance in comfortable, secure clothing that allows instructors to see alignment and movement.

  • Leotard, tights, and ballet slippers
  • Hair neatly secured away from the face
  • Dance warm-ups may be worn before class
  • Please label personal belongings
